# Astral Edition v2.0.0

Кастомный и легкий лаунчер для Amazing Online, созданный для быстрого запуска, стабильной производительности и удобного управления игровыми аккаунтами.

## Основные возможности

* **Менеджер аккаунтов**: Быстрое переключение и сохранение никнеймов по серверам.
* **Встроенный инжектор**: Удобный запуск и инжект DLL-модификаций в один клик.
* **Discord Rich Presence**: Отображение вашей активности в профиле Discord.
* **Гибкая настройка**: Выбор игрового процесса (`amazing.exe` или `gta_sa.exe`) и масштабирование интерфейса.
* **Атмосферный интерфейс**: Стильная темная тема, плавная боковая панель и подсветка за курсором.

## Установка

1. Скачайте актуальный билд лаунчера из раздела **Releases**.
2. Поместите исполняемый файл в удобную директорию.
3. Запустите от имени Администратора для корректной работы системных функций.
