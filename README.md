#  xaladzano-core

Custom lightweight launcher for Amazing Online. Built for fast connection and smooth performance without unnecessary overhead.

---

### What's inside

* **Fast Startup:** Bypasses bloated steps and launches straight into the game.
* **Low RAM & CPU Usage:** Keeps background processes to an absolute minimum.
* **Clean Build:** No junk files or useless services.

---

### Installation

1. Grab the latest release build.
2. Put `launcher.exe` into your game directory.
3. Run `launcher.exe` as Administrator and hop in.
