# Astral Launcher v2.0.0

Кастомный легкий лаунчер для Amazing Online, созданный для максимальной производительности, быстрого запуска и удобного управления игровыми аккаунтами.

## Основные особенности

* **Менеджер аккаунтов**: Удобное переключение, сохранение и удаление никнеймов отдельно для каждого сервера проекта в один клик.
* **Встроенный инжектор**: Быстрый выбор и инжект DLL-модификаций непосредственно через интерфейс лаунчера.
* **Discord Rich Presence**: Интеграция с Discord для отображения кастомной активности (`AMAZING ONLINE // Astral Edition`), статуса и таймера сессии в профиле.
* **Гибкая настройка процессов**: Возможность выбора основного исполняемого файла для запуска (`amazing.exe` или `gta_sa.exe`).
* **Масштабирование интерфейса**: Динамическая регулировка размера окна и элементов интерфейса (100%, 115%, 130%).
* **Атмосферный дизайн**: Строгая черная тема, плавное развертывание боковой панели, статический верхний фоновый фонарь и динамическая подсветка за курсором мыши.

## Технический стек

* **Язык**: Python
* **Интерфейс**: HTML5, CSS3, JavaScript (через `pywebview` и локальный веб-сервер)
* **Системные функции**: Автоматический запуск от имени Администратора через `ctypes`
* **Сборка**: Полная упаковка в единый исполняемый `.exe` файл через PyInstaller с защитой от консольного окна и поддержкой пользовательской `.ico` иконки

## Установка

1. Скачайте актуальный исполняемый файл из раздела релизов (Assets).
2. Поместите лаунчер в удобную директорию.
3. Запустите от имени Администратора для корректной работы системных функций и игровых процессов.
